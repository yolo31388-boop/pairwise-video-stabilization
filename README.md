# pairwise-video-stabilization

手持视频防抖在低纹理墙面越抖越漂，特征点只跟踪灰度，墙面没有角点就乱猜；平滑窗口按固定帧数，VFR 素材下时间跨度忽长忽短；裁切比例按最坏位移算，4K 素材被放大得只剩一半；滚动快门补偿只做全局平移，快速横摇时画面果冻；场景切换后轨迹没重置，新镜头先被甩一下；双目相机共用一条稳定轨迹，左右眼视差被抹平；10bit HDR 在 8bit 中间缓冲里算，防抖后高光断层；防抖后黑边没填充，边缘出现黑框；GPU 与 CPU 路径的平滑相位不同，预览和导出不一致；性能档直接关闭防抖，画面突然跳回原始抖动。media/video_stabilization.py 是核心，tests/test_video_stabilization.py 15个红。要修的是：低纹理用光流加惯性；窗口按时间而非帧数；裁切按分位位移；滚动快门按行时间补偿；切镜重置轨迹；双目独立轨迹；10bit 全链路；黑边反射填充；预览导出一致；降级做轻度平滑不关。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
